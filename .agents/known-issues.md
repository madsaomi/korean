## Осознанные компромиссы

1. **Антифарминг мягкий**: пересдача квиза ограничена кулдауном 30 сек
   (`quiz/views.py::RESUBMIT_COOLDOWN_SECONDS`), повторение требует due-слова
   с грейсом 5 сек (`review/services.py::DUE_GRACE_SECONDS`). Упорный пользователь
   всё равно накрутит счётчики — если нужна честность статистики, считать только
   лучшую попытку на квиз.
2. **grammar exercises** — состояние в сессии, гонка двух вкладок частично закрыта
   guard'ом `grammar_last_answered_index`, но полноценная серверная модель прохождения
   надёжнее.
3. **Пагинации у library API нет** (сознательно) — при тысячах заметок/закладок
   вернуть глобальную пагинацию.

## Инфраструктура перед продом

- Кэш по умолчанию LocMemCache (в процессе): rate limit TTS и кэш учебника не
  шарятся между воркерами. Для нескольких воркеров — Redis (`CACHES` в settings).
- Django сам не читает `.env`-файлы: переменные из `.env.example` экспортировать
  вручную или подключить django-environ.
- SQLite: `select_for_update()` фактически no-op между процессами; для реальной
  конкурентности — PostgreSQL.
- Медиа раздаются только при DEBUG; для прода нужен nginx/S3 + настройка MEDIA.
