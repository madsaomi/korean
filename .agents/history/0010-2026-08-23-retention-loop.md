## Что сделано

### Переучивание выученных слов (lapse-механика)
Проблема: после easy слово получало learned=True и **навсегда** исчезало из
повторения — долгосрочное удержание не работало.

Решение:
- Очереди повторения (8 мест: review_page, flashcard, api list,
  pending_review_count, context_processor, index/profile/dashboard) фильтруют
  только по `next_review <= now` БЕЗ `learned=False`. Выученное слово с наступившей
  датой возвращается в ротацию.
- `apply_review('again')` на выученном слове снимает learned → слово уходит в
  активное переучивание (10 мин, лестница заново). good сохраняет learned и
  двигает по лестнице дальше.
- words_learned (статистика «выучено») считается как раньше — статус learned,
  не очередь.

### Лидерборд без фарминга
- `top_quizzes`: Count('quiz_results') → Count('quiz_results__quiz', distinct=True)
  — считаются разные квизы, автопостинг одной формы больше не поднимает позицию.

### Тесты (+3, всего 118)
- again снимает learned с выученного слова;
- good сохраняет learned;
- pending включает learned-слова с наступившей датой и не включает после easy.
