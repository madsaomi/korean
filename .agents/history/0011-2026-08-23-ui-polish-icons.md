## Что сделано

### Фаза 1: Полишинг (коммит 01376c4)
- Бага невидимого крестика: `btn-close-white` → `btn-close` в модалках
  (base.html, library/detail.html) — теперь адаптируется к теме.
- SRI+crossorigin для bootstrap CSS/JS 5.3.3; confetti запинен на 1.9.3 c
  вычисленным локально SHA-384; preconnect для Google Fonts.
- `prefers-reduced-motion`: глобальное отключение анимаций в CSS + гейт confetti
  в main.js.
- Инлайн-стили → CSS: `.modal-content` (обе модалки), `.back-to-top`,
  `.dropdown-divider`, `button.dropdown-item`, `main .alert.glass-card`.
  Дропдауны: инлайны удалены как дублирующие существующие правила с !important.

### Фаза 2: Bootstrap Icons (коммит 0be2bcc)
- Подключён bootstrap-icons@1.11.3 (SRI вычислен локально).
- ~25 видов emoji заменены на `<i class="bi bi-*">` во всех 47 шаблонах
  (навигация, кнопки, дропдауны, футер, PWA-баннер, страницы ошибок).
  Замена выполнена скриптом с явным UTF-8 IO (код-поинты вместо литералов).
- Спейсинг иконок: CSS-правило margin для .bi рядом с текстом.
- Исправлены JS-места после замены: textContent → innerHTML в builder.html
  (copy/history), эмодзи результатов грамматики → bi-emoji-*.

### Инциденты по пути (уроки)
1. Bulk-замена через PowerShell pipeline (`Get-Content | Set-Content`) испортила
   кодировку двух шаблонов (UTF-8 прочитан как CP1251). Откат из git, повтор
   через [System.IO.File]::ReadAllText/WriteAllText с явным UTF-8 no BOM.
2. PowerShell 5.1 читает BOM-less .ps1 как ANSI — скрипты с не-ASCII литералами
   падают. Решение: код-поинты `[char]0xXXXX` вместо символов.
3. `git checkout` одного файла снёс незакоммиченные правки того же файла —
   восстановил все 5 правок base.html вручную.
