# HANDOFF — живая доска состояния

> **Единственный мутирующий файл в `.agents/`.** Всё остальное в history/ — append-only.
>
> Протокол для ЛЮБОГО агента (opencode / Codex / Claude Code / Cursor / Gemini CLI):
> 1. **Перед началом работы** — прочитай этот файл целиком. Если есть активная задача —
>    сначала доделай её по чеклисту, не начинай свою.
> 2. **Перед остановкой** (лимиты, конец сессии, прерывание пользователем) — ОБЯЗАТЕЛЬНО
>    обнови этот файл: что сделано, что осталось, где остановился. Без этого следующий
>    агент потеряет контекст.
> 3. Задача завершена → перенеси итог в журнал (`.agents/history/`, запись NNNN),
>    очисти блок «Активная задача».
> 4. Не доверяй этому файлу слепо: проверяй факты (`git status`, pytest) — файл может
>    быть устаревшим.
