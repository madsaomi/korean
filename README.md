# 🌸 K-Lab: Заметки и База знаний

Персональная база знаний по изучению **корейского** и **японского** языков на базе **Material for MkDocs** с прозрачным дизайном в стиле **iOS Glassmorphism & Liquid Design**.

---

## 🚀 Быстрый запуск

Дважды кликните по файлу:
```text
start.bat
```
Скрипт автоматически запустит локальный веб-сервер и откроет сайт в браузере по адресу:
👉 `http://127.0.0.1:8000/`

---

## 📁 Структура заметок

Все заметки находятся в папке `docs/`:

- `docs/korean/` — 🇰🇷 База заметок по корейскому языку (8 подробных глав от Хангыля до грамматики TOPIK).
- `docs/japanese/` — 🇯🇵 База заметок по японскому языку (Основы, Кандзи, JLPT N5/N4, Лексика, Справочники).
- `docs/assets/css/glassmorphism.css` — стили матового стекла, градиентов и эффектов iOS.

При любом редактировании файлов `.md` в папке `docs/` страница в браузере **обновляется мгновенно (Live Reload)**.
